LocalLense

LocalLense is a Spring Boot-based application for managing local product information.

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Gradle
- MySQL

Features

- Add Product
- View All Products
- Search Product by ID
- Update Product
- Delete Product

Project Structure

- src/
- gradle/
- build.gradle
- settings.gradle

How to Run

1. Clone this repository.
2. Open the project in VS Code or Eclipse.
3. Configure the database.
4. Run the Spring Boot application.
